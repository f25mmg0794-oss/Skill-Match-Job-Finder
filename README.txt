# SKILL MATCH JOB FINDER

## Project Description
Skill Match Job Finder is a Python-based DSA project that matches users' skills with available job opportunities and ranks jobs according to their skill compatibility.

## Technologies Used
- Python
- Flask
- HTML
- CSS
- Data Structures and Algorithms

## Installation Instructions
1. Install Python on your computer.
2. Open the project folder in VS Code.
3. Open the terminal.
4. Install Flask using:

   pip install flask

## How to Run
Run the following command in the terminal:

   python app.py

Open your browser and visit:

   http://127.0.0.1:5000

## Offline Support
The project uses a locally stored job dataset. An internet connection is not required to run the application.
